# Nexus Harness v4 — Runtime Adapters & Hooks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate Claude Code, Cursor and Codex configuration from one canonical source and enforce lifecycle/completion rules with structured hooks where supported.

**Architecture:** Each runtime adapter is a pure renderer. Claude receives the richest hook enforcement, Cursor receives always-on rules plus sandbox, and Codex receives minimal AGENTS/config; all generated outputs are drift-detected and atomically installed.

**Tech Stack:** Python 3.11+ standard library, JSON/TOML, shell wrappers, Claude/Cursor/Codex runtime configuration

**Spec:** `docs/superpowers/specs/2026-08-25-nexus-harness-v4-final-design.md`

## Global Constraints

- Python runtime floor is 3.11 so TOML is parsed with the standard-library `tomllib` module.
- Canonical machine configuration uses TOML/JSON; no YAML parser is introduced into the harness runtime.
- The original `nexus-harness-export-20260825-094238.tar.gz` is immutable; all destructive cleanup occurs only in a v4 working copy.
- No project-specific IP, SSH target, absolute project path, client secret or model name belongs in `core/constitution.md`.
- Generated `dist/` content is never edited by hand; drift is a validation failure.
- Tests use Python standard-library `unittest` unless a target project already has its own test runner.
- Every implementation task is performed test-first where behavior can be isolated.
- Claude, Cursor and Codex are generated artifacts, not sources of truth.
- Project-specific production rules are emitted only from an explicit project profile.
- Stop/completion hooks must not create infinite hook loops.

from nexus_harness.install import atomic_install

class InstallTests(unittest.TestCase):
    def test_existing_install_is_backed_up_before_replace(self):
        with tempfile.TemporaryDirectory() as tmp:
            root = Path(tmp)
            source = root / "dist"
            target = root / "installed"
            source.mkdir(); target.mkdir()
            (source / "a").write_text("new")
            (target / "a").write_text("old")
            backup = atomic_install(source, target)
            self.assertEqual((target / "a").read_text(), "new")
            self.assertEqual((backup / "a").read_text(), "old")
